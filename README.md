# Jergan Studio Website 🌑

Official Jergan Studio website — a lightweight static site built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

No Node.js, npm, build step, or framework is required.

## Deploy

### GitHub Pages

The repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`. In GitHub, open **Settings → Pages**, select **GitHub Actions** as the source, and push to `main`.

### Vercel

Import `jergan-studio/Jerganstudio` into Vercel. The project is already static, so no build command is required. Set the output directory to the repository root if Vercel asks for one.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- GitHub Pages / Vercel compatible
